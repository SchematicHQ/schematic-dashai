# Schematic DashAI

DashAI is an AI-powered dashboard builder that demonstrates how to integrate [Schematic](https://schematichq.com) into real-world applications. These are fully working reference implementations across the three major frontend frameworks, showing how to use Schematic's SDKs for feature flags, entitlements, usage-based billing, and embedded pricing components.

Try it live: **[schematic-dashai.vercel.app](https://schematic-dashai.vercel.app/)**

## Implementations

Each folder is a standalone project with its own dependencies and build configuration.

| Framework | Folder | Status |
|-----------|--------|--------|
| React (Next.js) | `react/` | Available |
| Angular | `angular/` | Available |
| Vue | `vue/` | Available |

## Getting Started

Pick a framework and follow the README in that folder.

```bash
cd react    # or angular, vue
yarn install
yarn dev
```

Each implementation needs a Schematic API key. Sign up at [schematichq.com](https://schematichq.com) to get one.
